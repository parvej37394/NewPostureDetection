# PoseNet Real-Time Pose Detection

## Project Overview
This project uses **ml5.js PoseNet**, **p5.js**, and JavaScript to perform real-time human pose detection through a webcam.

It detects human body keypoints and visualizes the body skeleton in real time. It also overlays an image on the detected nose position.

## Features
- Real-time webcam integration
- Human body keypoint detection
- Skeleton visualization
- Nose position tracking
- Custom image overlay
- Browser-based application

## Technologies Used
- HTML5
- CSS
- JavaScript
- p5.js
- ml5.js (PoseNet)

## How to Run
1. Clone this repository.
2. Open the project in VS Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select Open with Live Server.
6. Allow webcam access.
